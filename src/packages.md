# All packages

PHP 8.3+, SemVer, backward-compatibility checks, Testo tests (PHPUnit for one adapter) with mutation gates. Every package ships an `llms.txt`; forty-three also ship an agent skill that the [llm/skills](https://github.com/roxblnfk/skills) Composer plugin installs. Versions, gates and skills are read from Packagist and the tagged sources when the site is built. Every package has a manual page here; `man` marks the hand-written ones with examples.
