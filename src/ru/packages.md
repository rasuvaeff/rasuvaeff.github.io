# Все пакеты

PHP 8.3+, SemVer, проверки обратной совместимости, тесты на Testo (у одного адаптера на PHPUnit) с мутационными порогами. В каждом пакете есть `llms.txt`; в сорока ещё и навык для агента, который ставит Composer-плагин [llm/skills](https://github.com/roxblnfk/skills). Версии, пороги и навыки берутся с Packagist и из тегированных исходников при сборке сайта. У пакетов с пометкой `man` здесь есть man-страница. Описания пакетов даны на английском, как в `composer.json`.
